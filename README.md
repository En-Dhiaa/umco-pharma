# منصة شركة يمكو للصناعات الدوائية والطبية | YUMCO Pharmaceuticals Platform
> **Enterprise Bilingual Pharma Web Platform, Operations & Marketing / HR Management System**  
> Developed for **YUMCO Pharmaceuticals** (شركة يمكو للصناعات الدوائية والطبية) — Sana'a, Yemen.

---

## 🌟 نظرة عامة | Overview
منصة دوائية وصناعية متطورة ثنائية اللغة (عربي / إنجليزي) مصممة وفق أحدث المعايير العالمية لكبرى شركات الأدوية العالمية (WHO-GMP / ISO Standards). تجمع المنصة بين:
1. **الموقع المؤسسي والكتالوج الدوائي التفاعلي (Public Pharmaceutical Portal):**
   - استعراض الكتالوج الطبي المتكامل مع تصنيفات تفاعلية وفلاتر دقيقة ومواصفات دوائية.
   - **خريطة الفروع التفاعلية (Interactive Leaflet Map):** خريطة جغرافية لجميع فروع يمكو في عموم محافظات اليمن مع إحداثيات GPS دقيقة، وتحديد المقر الرئيسي، وأيقونات مخصصة، وإمكانية الانتقال المباشر للفرع بنقرة زر (`flyTo`).
   - **قسم الحملات الطبية والتوعوية (Medical Campaigns & Announcements):** لنشر الفعاليات، تدشين الأدوية، وحملات مكافحة العدوى بالمشافي.
   - **الدليل الدوائي السريري (Clinical Dosage & Indications Guide):** مرجع تفاعلي للأطباء والصيادلة للجرعات ودواعي الاستعمال.
   - **شراكات التصنيع للغير (Contract & Toll Manufacturing):** حلول التصنيع التعاقدي والتعبئة المعقمة تحت العلامة الخاصة (Private Label).
   - **ودجت "اسأل الصيدلي / الاستفسار الطبي" (Ask Pharmacist Live Support):** استفسارات مباشرة من الأطباء والصيادلة والمرضى مع ردود فورية.
   - منظومة خطوط الإنتاج المؤتمتة الثلاثة ومختبرات ضبط وتأكيد الجودة (QC/QA).
   - طلبات عروض الأسعار والتوريد (B2B & RFQ Quotation Builder).
   - بوابة التيقظ الدوائي والإبلاغ عن الآثار الجانبية (Pharmacovigilance Hub).

2. **بوابة إدارة العمليات والهوية الرقمية (Enterprise IT & Operations Portal):**
   - **نظام تخصيص الهوية والشعار والألوان (Brand & Theme Customizer):**
     - تحكم كامل من مدير تقنية المعلومات (IT Director) والمدير العام في ألوان الموقع الأساسية والفرعية والتفاعلية مع معاينة فورية وحفظ في قاعدة البيانات.
     - إدارة الشعار (Logo): التحكم بنص الشارة، رابط صورة الشعار، شريط تمرير الحجم (32px - 64px)، واسم الشركة وشعارها بالعربية والإنجليزية.
     - إدارة الخطوط والطباعة (Typography): اختيار الخطوط العربية (Cairo, Tajawal, Almarai, Readex Pro, IBM Plex Sans Arabic) والإنجليزية (Outfit, Inter, Plus Jakarta Sans, Roboto)، وحقل لتحميل أي خط خارجي من Google Fonts مع معاينة حية ومباشرة.
     - إدارة روابط التنقل العلوية (Navbar Links) وروابط التواصل الاجتماعي (WhatsApp, Facebook, LinkedIn, Telegram, Email).
   - **إدارة الفروع المتكاملة (Branches Management CRUD):** إضافة وتعديل وحذف الفروع مع إحداثيات GPS وبيانات المدير وساعات العمل والتفعيل/التعطيل.
   - **إدارة المنتجات والأدوية (Products Management CRUD):** إضافة وتعديل وحذف الأصناف الدوائية والتركيبات والتصنيفات والأسعار.
   - **إدارة الموظفين المتكاملة (Employees Directory & Lifecycle):** إضافة وتعديل وحذف الموظفين مع توزيع المهام ومتابعة الحالة.
   - **حساب ومستخدم التسويق الطبي (Marketing Specialist):** نشر الحملات والإعلانات الطبية، نشر وإدارة الكتالوج الدوائي، ومراجعة والرد على استفسارات العملاء.
   - **نظام مهام الموظفين التفاعلي (Employee Tasks & Kanban):** توزيع المهام، تحديد الأولويات والمواعيد، لوحة كانبان تفاعلية، وتتبع الإنجاز.
   - **نظام الإشعارات المباشر (Real-time Notifications Center):** تنبيهات فورية للمهام، الاستفسارات، عروض الأسعار، وبلاغات الجودة.

## 🚀 التقنيات المستخدمة | Tech Stack
- **الواجهة الخلفية (Backend):** Node.js / Express.js مع معمارية RESTful API محكمة وموثقة.
- **قاعدة البيانات (Database):** SQLite3 عالية الأداء مع وضع WAL ومعاملات ذرية وتغذية أولية كاملة للبيانات (Seeding).
- **الخرائط التفاعلية (Geospatial Mapping):** Leaflet.js مع خرائط CartoDB Voyager عالية الدقة بدون الحاجة لمفاتيح API تجارية.
- **الأمان والصلاحيات (Auth & Security):** JWT Tokens, bcrypt password hashing, RBAC Middleware, Rate Limiting, CORS, Input Validation.
- **الواجهة الأمامية (Frontend):** Modern Reactive UI مع نظام تصميم طبي مخصص (Deep Pharma Navy & YUMCO Crimson)، دعم كامل للـ RTL/LTR، أيقونات تفاعلية، ولوحات تحكم ديناميكية.
- **إدارة المستودع (GitHub):** مستودع خاص تحت حساب [En-Dhiaa/umco-pharma](https://github.com/En-Dhiaa/umco-pharma).
